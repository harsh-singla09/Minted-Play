# 🎮 Minted Play

Minted Play is a modern gaming and creator ecosystem designed to connect **Gamers, Creators, Brands, and Communities** through an immersive digital experience.

Built with a modern gaming-inspired UI, Minted Play provides multiple features including creator pages, blogs, shopping functionality, user authentication interfaces, dashboards, and community-focused experiences.

### 🎮 Gaming Experience

* Modern gaming-inspired UI
